# Calculadora en C#

Este proyecto es una calculadora de consola para principiantes en C#.

## Operaciones

- Suma (+)
- Resta (-)
- Multiplicación (*)
- División (/)
- Módulo (%)
- Potencia (**)
- Raíz (root)
- Historial
- Salir

## Requisitos

- .NET 8 SDK

## Ejecutar

```bash
dotnet run
```

## Nota

El historial se guarda en un archivo llamado `historial.txt` dentro de la carpeta de salida del proyecto.
